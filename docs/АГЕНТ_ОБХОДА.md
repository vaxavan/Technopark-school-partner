# Проверка сайтов школ, если сервер они не пускают

Система раз в сутки открывает сайты школ и ищет на них разосланный материал. Некоторые школьные сайты
(например, на платформе edumsko.ru) не принимают подключения с адресов хостинга: с домашнего или офисного
компьютера сайт открывается, а с сервера — нет. Признак в проверке подключений (`./prod.sh check`):

```
[ОШИБКА] Сайт школы: ... не принимает подключение с этого сервера за 10 с
```

Сам сервер эту проблему не решит — нужен другой адрес. Есть три пути, их можно сочетать.

## 1. Школа подтверждает сама (работает всегда)

В каждом письме школе есть персональная ссылка «пришлите ссылку на публикацию». Школа вставляет адрес
поста — система сама сверяет текст. Ничего настраивать не нужно.

Пока сайт школы не открывается, система **не ставит** ей «Не найдено» — в журнале обход пишет
«не проверено (сайт не открылся)». Напоминания уходят как обычно: в них та же ссылка.

## 2. Агент обхода на компьютере, где сайты открываются (рекомендуется)

Агент — небольшая программа. Она берёт у системы список сайтов, сама открывает их с этого компьютера и
присылает найденные публикации. Сверку, решения и отчёт делает система, как при обычном обходе.
Пока агент отчитывается (последние 36 часов), сервер сайты школ сам не обходит.

### Шаг 1. Ключ агента

«Настройки» → «Проверка сайтов школ с другого компьютера» → **Создать ключ агента**. Ключ показывается
один раз — скопируйте его. Если ключ потерялся, выдайте новый: старый перестанет работать.

### Шаг 2. Установка на Windows

1. Установите Python 3.12 с [python.org](https://www.python.org/downloads/). В установщике отметьте
   **Add python.exe to PATH**.
2. Скачайте код системы с GitHub (кнопка **Code → Download ZIP**) и распакуйте, например, в `C:\technopark`.
3. Откройте PowerShell и выполните:

```powershell
cd C:\technopark
python -m pip install -r scripts\agent-requirements.txt
python scripts\crawl_agent.py --server http://159.194.245.202:8080 --token agt_ВАШ_КЛЮЧ
```

Агент напишет, какие сайты открылись и что подтверждено. В «Настройках» появится «Агент: работает».

### Шаг 3. Запуск каждый день

Компьютер должен быть включён в это время. В PowerShell (одна строка, путь и ключ — свои):

```powershell
schtasks /Create /TN "Технопарк агент обхода" /SC DAILY /ST 08:00 /TR "python C:\technopark\scripts\crawl_agent.py --server http://159.194.245.202:8080 --token agt_ВАШ_КЛЮЧ"
```

Удобнее время после начала рабочего дня. Напоминания школам сервер отправляет в `CRAWL_HOUR + 3`
(по умолчанию в 9:00), поэтому агенту лучше успеть до этого. Если компьютер работает постоянно, можно
вместо планировщика запустить агента с повтором: `... --every 12` (каждые 12 часов).

### Через Docker вместо Python

Если на компьютере уже есть Docker и папка с кодом:

```bash
docker compose run --rm --no-deps web python manage.py crawl_agent --server http://159.194.245.202:8080 --token agt_ВАШ_КЛЮЧ
```

## 3. Прокси с российским адресом

Если есть прокси (у провайдера или свой), укажите его в `.env` на сервере и перезапустите систему:

```
CRAWLER_PROXY=http://логин:пароль@адрес:3128
```

Через прокси идут только обращения к сайтам школ (обход и снимки страниц). ВКонтакте, Telegram и
YandexGPT работают напрямую. Проверка: `./prod.sh check`.

## Как понять, что помогло

- `./prod.sh check` — по каждому сайту видно, открылся ли он и сколько публикаций найдено;
- «Журнал» — записи «Обход агентом: …» или «Проверено размещений: …»;
- «Отчёт по школам» — подтверждённые размещения со снимками страниц.
