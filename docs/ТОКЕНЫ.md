# Где взять ключи и токены

Система работает и без ключей: всё, что не настроено, работает в **демо-режиме** (видно на странице «Настройки»).
Подключайте сервисы по одному. После каждого запускайте проверку:

```bash
docker compose exec web python manage.py check_integrations
```

Ключи вписываются в файл `.env` в корне проекта (образец — `.env.example`). После правки `.env`:

```bash
docker compose up -d
```

Токены ВКонтакте и Max можно ввести и в интерфейсе: «Настройки» → блок площадки. Там они хранятся
в базе в зашифрованном виде, и эти значения важнее, чем значения из `.env`.

> ⚠️ Файл `.env` нельзя коммитить в git (он уже в `.gitignore`). Ключ, который попал в git, нужно перевыпустить.

## 1. YandexGPT (Yandex AI Studio) — уже есть

Ключ и ID каталога из прототипа (`legacy/TechnoparkTest/.env`) переносятся в `.env` как есть:

```
YANDEX_API_KEY=AQVN...
YANDEX_FOLDER_ID=b1g...
YANDEX_MODEL=yandexgpt/latest          # тексты
YANDEX_MODEL_LITE=yandexgpt-lite/latest  # уточняющие вопросы (дешевле и быстрее)
```

Если ключ нужно выпустить заново:

1. Откройте console.yandex.cloud → нужный каталог (его ID — это `YANDEX_FOLDER_ID`, начинается с `b1g`).
2. «Сервисные аккаунты» → создайте аккаунт с ролью **`ai.languageModels.user`**.
3. В аккаунте: «Создать новый ключ» → «Создать API-ключ». Значение (начинается с `AQVN`) — это `YANDEX_API_KEY`.

Проверка покажет, отвечает ли модель и возвращает ли она JSON по схеме.

## 2. Почта (SMTP) — рассылка школам и письма авторам

Нужен отдельный ящик технопарка, например на Яндексе.

**Яндекс Почта**
1. Войдите в ящик → «Все настройки» → «Почтовые программы».
   Включите **«С сервера imap.yandex.ru по протоколу IMAP»** и **«Пароли приложений и OAuth-токены»**.
2. Откройте id.yandex.ru → «Безопасность» → **«Пароли приложений»** → «Почта» → придумайте название
   (например, «Система публикаций»). Пароль показывается **один раз** — скопируйте его.
3. В `.env`:
   ```
   EMAIL_HOST=smtp.yandex.ru
   EMAIL_PORT=465
   EMAIL_USE_SSL=1
   EMAIL_HOST_USER=press@yandex.ru      # полный адрес
   EMAIL_HOST_PASSWORD=пароль_приложения # НЕ обычный пароль от ящика
   DEFAULT_FROM_EMAIL=press@yandex.ru
   ```
4. Проверка с тестовым письмом:
   `docker compose exec web python manage.py check_integrations --mail-to ваш@адрес`

**Mail.ru:** `EMAIL_HOST=smtp.mail.ru`, порт 465, SSL. Пароль создаётся в «Настройки» → «Безопасность» →
«Пароли для внешних приложений» (к ящику должен быть привязан телефон).

**Ограничения.** У Яндекса около 500 писем в сутки с одного ящика. Система отправляет каждой школе отдельное
письмо с паузой (`MAIL_PAUSE_SECONDS=2`) и заголовком отписки, поэтому 150 школ укладываются в лимит.
Если письма начнут попадать в спам, увеличьте паузу. Для своего домена настройте SPF и DKIM.

**E-mail школ** вносятся в «Справочник школ» (карточка школы) или столбцом «E-mail» в Excel при импорте.
Пока у школы нет e-mail, рассылка ей не уходит, но размещение на её сайте всё равно проверяется.

## 3. ВКонтакте — публикация в сообщество технопарка

### Что важно знать заранее (правила ВК на 2026 год)
- **Ключ сообщества не подходит.** Чтобы загружать фото на стену, нужен ключ **пользователя**:
  администратора или редактора группы, с правами `wall` и `photos`.
  С ключом сообщества `photos.getWallUploadServer` возвращает ошибку 27.
- С 25.06.2024 старый способ получения ключа (Implicit Flow) **отключён**. Ключ выдаётся через **VK ID**.
  Новым приложениям права `wall`/`photos` выдают **по заявке** на devsupport@corp.vk.com.
- Если у кого-то в технопарке уже есть **бессрочный** ключ пользователя (`offline`), выпущенный раньше, он
  продолжает работать. Это самый простой путь.

### Шаги
1. **ID группы.** Откройте группу. Если адрес вида `vk.com/club123456`, ID — `123456`.
   Если адрес короткий (`vk.com/istok_tech`), откройте любой пост группы: в адресе `wall-123456_789` ID — `123456`.
2. **Приложение VK ID.** Перейдите на id.vk.ru/business/go и создайте приложение. Понадобится подтверждённый профиль
   организации или ИП.
3. **Права.** В настройках доступа приложения запросите `wall`, `photos`, `groups`. Если их нет в списке, напишите на
   **devsupport@corp.vk.com**. Укажите, что приложение публикует новости образовательной организации
   в её собственное сообщество от имени сообщества, и приложите ID приложения и ID группы.
4. **Ключ пользователя.** Администратор группы входит через VK ID, приложение получает `access_token`.
   Ключ VK ID живёт 1 час и продлевается через `refresh_token`. Для такого ключа система пока не делает
   автопродление. Если выдадут бессрочный ключ — просто вставьте его.
5. В `.env` (или в «Настройки» → ВКонтакте):
   ```
   VK_GROUP_ID=123456          # без минуса
   VK_ACCESS_TOKEN=vk1.a....   # ключ пользователя-администратора
   ```
6. `check_integrations` покажет «группа найдена» и «есть право загружать фото на стену».
   Если права на фото нет, пост всё равно уйдёт, но без фото — система это переживёт.

### Проверка размещения у школ во ВКонтакте (необязательно)
Чтобы система читала стены сообществ школ, нужен **сервисный ключ** любого вашего приложения VK:
в настройках приложения → «Сервисный ключ доступа». В `.env` впишите `VK_SERVICE_TOKEN=...`.
Затем в карточке школы добавьте источник «Сообщество ВКонтакте» с адресом группы школы.

> Пока ВКонтакте не подключён, публикация идёт в демо-режиме: пост «выходит» на внутреннюю страницу
> системы, снимок и доказательство создаются по-настоящему. Если пост в ВК публиковали руками, на экране материала
> есть кнопка «Вышло»: вставьте ссылку на пост.

## 4. Max — публикация в канал

### Что важно знать
- Бота может создать только **верифицированная организация, ИП или самозанятый — резидент РФ**,
  на платформе **business.max.ru** («MAX для партнёров»). Пользователям бот доступен после модерации.
- API: `https://platform-api2.max.ru`, ключ передаётся в заголовке `Authorization`.

### Шаги
1. business.max.ru → войдите от имени организации → «Чат-боты» → «Создать». Дождитесь модерации.
2. В боте: «⋮» → «Настройки» → **токен**. Это `MAX_BOT_TOKEN`.
3. Добавьте бота в канал технопарка **администратором** с правом **публиковать** (write)
   и **читать все сообщения**.
4. **chat_id канала.** Готового списка каналов в API нет: ID приходит боту в событии `bot_added`, когда его
   добавляют в канал. Самый простой способ:
   - добавьте бота в канал;
   - в течение суток выполните (подставьте токен):
     ```bash
     curl -H "Authorization: ВАШ_ТОКЕН" "https://platform-api2.max.ru/updates"
     ```
   - найдите в ответе `"update_type": "bot_added"` и рядом `"chat_id": -123456789`. Это `MAX_CHAT_ID`.
5. В `.env` (или в «Настройки» → Max):
   ```
   MAX_BOT_TOKEN=...
   MAX_CHAT_ID=-123456789
   ```
6. **Сертификат.** Серверы Max используют сертификат Минцифры. Если `check_integrations` пишет об ошибке
   сертификата, скачайте корневой сертификат «Russian Trusted Root CA» с gosuslugi.ru/crt, положите его в папку
   `data/` и укажите `MAX_CA_BUNDLE=/app/data/russian_trusted_root_ca.pem`.

Ограничения Max: текст поста до 4000 знаков (система готовит до 1500), не больше 30 запросов в секунду.

## 5. Дзен — через RSS-ленту (ключ не нужен)

Дзен сам забирает материалы из ленты системы: `https://ваш-домен/rss/istok.xml`.
Адрес ленты указан на странице «Настройки».

Условия Дзена:
- у канала не меньше **10 подписчиков**;
- лента должна быть на **том же домене**, что и сайт, подключённый к каналу; домены `.рф` не подходят;
- значит, систему нужно разместить на сервере с доменом. С `localhost` Дзен ленту не увидит.

Шаги в Студии Дзена:
1. «Настройки» → «Свой сайт» → добавьте домен и подтвердите его (HTML-файлом или мета-тегом).
2. «Настроить трансляцию материалов сайта в Дзен» → вставьте адрес RSS-ленты → «Отправить на проверку».
3. Если откажут по технической причине, можно подать снова сразу. Если по содержанию — только через 6 месяцев.
   В ленте должны быть материалы с фото и достаточно длинным текстом (система готовит для Дзена от 700 знаков).

До подключения Дзена материал всё равно попадает в ленту и на публичную страницу `/n/istok/<id>/`.

## Сводка

| Сервис | Что нужно | Без него |
|---|---|---|
| YandexGPT | `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` (есть) | демо-модель собирает текст из заявки |
| Почта | ящик + пароль приложения | письма лежат файлами в `media/outbox` |
| ВКонтакте | ID группы + ключ пользователя-админа (права wall, photos) | демо-публикация на внутренней странице |
| Max | бот организации + chat_id канала | демо-публикация |
| Дзен | домен + канал от 10 подписчиков | лента работает, Дзен её не забирает |
| ВК школ | сервисный ключ приложения | стены школ не проверяются, сайты — проверяются |
