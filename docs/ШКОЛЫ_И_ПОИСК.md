# Школы-партнёры: контроль размещения и поиск по сайтам

В системе два разных способа работать с сайтами школ.

| | Контроль размещения | Поиск по теме |
|---|---|---|
| Что ищем | наш разосланный материал (его текст) | любые публикации на тему: «битва роботов» |
| Когда | автоматически каждую ночь после рассылки | когда вы запустили поиск |
| Как сравниваем | текст целиком: доля совпадающих цепочек слов | фраза или слова рядом, в любой форме («битве роботов») |
| Где смотреть | «Отчёт по школам» | «Поиск по сайтам школ» |
| Выгрузка | Excel и «Снимки (ZIP)» | Excel «есть / нет» и «Архив со снимками (ZIP)» |

## 1. Контроль размещения нашего материала

1. Материал с площадкой «Рассылка школам» после выхода уходит письмом всем активным школам.
   В письме — текст, фото и персональная ссылка «прислать ссылку на публикацию».
2. Каждую ночь (`CRAWL_HOUR`) система открывает источники школ из «Справочника школ»: карту сайта,
   RSS, раздел новостей, сообщество ВКонтакте — и ищет там наш текст.
3. Совпадение 60% и больше — «Подтверждено»: система сохраняет снимок страницы и копию HTML с
   контрольной суммой. 35–60% — «Требует решения»: администратор смотрит и подтверждает или отклоняет.
4. Если за отведённый срок ничего не нашлось — «Не найдено» (только если сайт школы открывался;
   недоступный сайт так не помечается). Школам без ответа уходят до двух напоминаний.
5. «Отчёт по школам» → «Выгрузить в Excel» (таблица) и «Снимки (ZIP)» (папка на материал, внутри —
   по школам: снимок, копия страницы, ссылка).

Проверить одну школу сразу: «Справочник школ» → школа → «Проверить сейчас».

## 2. Поиск по теме («была ли у школ новость про битву роботов»)

«Поиск по сайтам школ» → введите фразу, период, при необходимости выберите школы → «Начать поиск».

- Фраза ищется в любой форме: «битва роботов» найдёт «в битве роботов», «битвы роботов». Несколько
  фраз через запятую — подойдёт любая: `битва роботов, технопарк Исток`.
- Сайт обходится целиком, а не только наши источники: раздел «Новости»/«События» со всеми страницами
  списка, карта сайта, RSS. За один поиск читается до 150 страниц школы; сначала — те, где нужные
  слова видны уже в заголовке, затем самые свежие.
- Каждая школа проверяется отдельной фоновой задачей, страницу можно закрыть. Прогресс виден на
  странице поиска.
- Результат по школе: **Есть** (со ссылками, датами, фрагментами текста, снимками),
  **Нет**, **Сайт не открылся**, **Нет адреса сайта** (заполните «Сайт» в справочнике).
- **Excel «есть / нет»**: лист «Школы» — по строке на школу; лист «Публикации» — все найденные
  страницы с датами, ссылками и именами файлов снимков.
- **Архив со снимками (ZIP)**: `Итоги.xlsx` и папка на каждую школу:
  `13 МАОУ СОШ №16 ГОЩ/2026-10-12 Наши победы (41).png` и `.html`.

Если сайты не открываются с сервера, поиск выполняет агент обхода на компьютере, где они открываются
(см. [АГЕНТ_ОБХОДА.md](АГЕНТ_ОБХОДА.md)). Снимки у агента получаются, если на том компьютере
установлен Playwright: `python -m pip install playwright` и `python -m playwright install chromium`;
без него сохраняются копии страниц (HTML).

Ограничения: страницы, которые подгружаются только кнопкой «Показать ещё» (без адресов страниц списка),
и новости только в PDF-файлах не читаются. Очень старые новости находятся, если они есть в карте
сайта или в списке новостей сайта.
